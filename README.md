## 🌟 О проекте

Этот проект создан, чтобы показать детям, что история космоса — это не скучные энциклопедии, а настоящее приключение. Сайт полностью адаптирован под детское восприятие: используются крупные шрифты, яркий визуальный стиль, анимированный звездный фон и интерактивные элементы.

### 🎮 Главные фишки и особенности:

* **Интерактивная карта героев:** Можно навести на любую точку и узнать, какой космонавт или конструктор родился в этом регионе.
* **Игровые маскоты (Белка и Стрелка):** Собачки-космонавты парят в левом нижнем углу, реагируют на действия пользователя, дают подсказки, проводят обучающие туры по сайту и рассказывают интересные факты.
* **Геймификация:** Встроенная система достижений (медалей), за которые нужно читать статьи, проходить квизы и играть в мини-игры.
* **Игровая зона:** Аркада «Космический рейс», Авиаконструктор и интерактивные схемы устройства ракеты, самолета и лунохода.
* **Пасхалки (Секреты):** Эффект невесомости, звук лая, звездопад в поиске и секретные штампы.
* **Безопасность:** На сайте нет рекламы, сбора персональных данных и сложной регистрации.

## 🛠 Технологии

Проект написан с нуля без использования тяжелых фреймворков, что обеспечивает быструю загрузку и отличную работу даже на слабых устройствах:

* **HTML5** (семантическая разметка)
* **CSS3** (Flexbox, CSS Grid, анимации, стиль Glassmorphism)
* **Vanilla JavaScript** (игровая логика, работа с Canvas API для звездного неба, LocalStorage для сохранения достижений)
* **Адаптивная верстка** (поддержка ПК, планшетов и смартфонов)

## 🚀 Как запустить проект

Вам не нужно устанавливать сервер или базы данных. Достаточно:

1. Скачать архив с проектом.
2. Распаковать его в любую папку.
3. Открыть файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
